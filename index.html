🌐 El viaje secreto de una dirección web

¿Qué ocurre cuando escribimos una dirección en Internet?

Proyecto de Digitalización · 4.º ESO

1. ¿Qué es el DNS?

DNS significa Sistema de Nombres de Dominio. Es un sistema que ayuda a encontrar la dirección IP asociada a un nombre de dominio.

Funciona como una agenda: buscamos el nombre de una web y el DNS nos ayuda a encontrar su dirección.

2. ¿Por qué usamos nombres?

Es más fácil recordar wikipedia.org que una serie de números. Los ordenadores utilizan direcciones IP para comunicarse a través de la red.

Nombre: wikipedia.org
IP: una dirección numérica que debemos consultar.

3. El viaje para encontrar una IP

Paso 1. Escribimos una dirección web en el navegador.
Paso 2. El ordenador comprueba si ya conoce la IP y puede tenerla guardada en la caché.
Paso 3. Si necesita buscarla, pregunta a un servidor DNS.
Paso 4. El DNS busca la información necesaria y devuelve una dirección IP.
Paso 5. El navegador utiliza esa IP para conectarse al servidor de la web.
Paso 6. El servidor responde y el navegador muestra la página.

4. ¿Qué ocurre cuando tenemos la IP?

El navegador ya puede intentar conectarse al servidor correspondiente. Después se comunica con él y recibe los datos necesarios para mostrar la página web.

Encontrar la IP es un paso del proceso: no significa que la página se haya cargado automáticamente.

5. La caché DNS y el TTL

Caché DNS: es una memoria temporal que guarda respuestas DNS para evitar repetir algunas búsquedas.

TTL: significa tiempo de vida. Indica cuánto tiempo puede conservarse una respuesta DNS en caché antes de que deba actualizarse o volver a consultarse según las reglas del sistema.

6. ¿Una web puede tener varias IP?

Sí. Una web puede tener varias direcciones IP. Esto puede ayudar a repartir las conexiones, mejorar la disponibilidad o utilizar servidores diferentes.

La dirección que recibimos puede variar según el servicio, la ubicación y el momento de la consulta.

8. Conclusión

El DNS facilita el uso de Internet porque permite encontrar direcciones IP a partir de nombres de dominio. Gracias a este sistema podemos utilizar nombres fáciles de recordar en vez de memorizar direcciones numéricas.
